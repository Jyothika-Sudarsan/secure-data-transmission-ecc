# 🔐 Secure Data Transmission Framework using ECC

## 📌 Overview

This project implements a secure data transmission system for **text, images, and videos** using **Elliptic Curve Cryptography (ECC)**.

It focuses on comparing the efficiency of two widely used elliptic curves:

* **Curve25519**
* **secp256r1**

The project demonstrates that **Curve25519 provides better performance and efficiency** for secure communication.


## ⚙️ Features

* 🔒 Encryption and decryption of text, images, and video data
* 🔑 Secure key exchange using ECC
* 📊 Performance comparison of Curve25519 and secp256r1
* ⚡ Faster and efficient computations using Curve25519


## 🧪 Technologies Used

* **Language:** Python
* **Concepts:** Elliptic Curve Cryptography (ECC), Encryption/Decryption
* **Data Types:** Text, Image, Video


## 📊 Results

* Curve25519 shows **faster execution time**
* Lower computational overhead
* More suitable for real-time secure transmission

This project proves that **Curve25519 outperforms secp256r1** in terms of speed and efficiency, making it a better choice for modern cryptographic applications.
